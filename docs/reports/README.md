### Abstract (summary)

Rigorous re-evaluation of deep learning for Alzheimer's disease stage classification from ADNI structural MRI (*n*=320), introducing **Liquid Finder** preprocessing, exposing slice-level evaluation leakage (16–32 pp inflated accuracy), reporting patient-level OvA benchmarks, and validating predictions with Grad-CAM, LIME, and SHAP on periventricular regions.
